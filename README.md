# M5StickC Plus SE ミニゲーム集

K016-P-SE向けに、ホームラン競争・チキン風船・記憶スイッチ・声で浮く気球・ぴったり10秒を実装しています。Wi-Fi、スマートフォン、外付けセンサーは不要です。通常版の実機書き込みとハッシュ照合に成功しています。起動ログ・実際の表示や遊びやすさは未検証です。

## ビルド

```sh
# PythonとPlatformIO Core 6.2.0を用意した上で実行
pio run -e m5stick-c-se
sh scripts/test.sh
```

固定構成：Espressif32 6.12.0、Arduino-ESP32 2.0.17（PlatformIOパッケージ `3.20017.241212+sha.dcc1105b`）、Xtensa GCC `8.4.0+2021r2-patch5`、esptool 4.9.0（パッケージ `2.40900.250804`）。M5Unified 0.2.23・M5GFX 0.2.30はローカルの同版キャッシュから `lib/` にソースを同梱して固定しました。ライブラリは追加ダウンロード不要ですが、初回のツールチェーン取得にはネット接続が必要です。C++17を使用します。

ホストテストにはC++17コンパイラとAddressSanitizer/UndefinedBehaviorSanitizerが必要です。macOSでXcodeのSDKとCommand Line ToolsのSDKに差がある場合、スクリプトはインストール済みXcodeのSDKを選びます。

公式Factory ZIPのコミットは `1b24c43905c0c74b5f83b9668117a01ffdd7fee6`。同じ `board = m5stick-c`、4MB Flash、3MBアプリ領域、横画面rotation=3を採用しています。SE専用board IDは追加していません。M5GFXの有効な自動検出処理がSEのLCDを `board_M5StickCPlus` として扱い、M5Unifiedの同じ経路がAXP192・PDMマイク・ブザーを設定します。IMU/RTCは無効です。

Factory `test.h` のコメント内LCD定義（DC=14/RST=12/BL=27）は、実際の `lcd.begin()` に使われていません。公式SE PinMapと実行されるM5GFXの経路に合わせ、DC=23/RST=18、MOSI=15/SCLK=13/CS=5、AXP192によるバックライト制御を使います。GPIO4を電源保持ピンとして操作せず、M5UnifiedのSEと対応するAXP192初期化に任せています。初期化後の検出結果・解像度をSerialへ出し、StickCPlusとして検出できない場合はゲームを始めず確認画面を表示します。これはSEの実機動作を保証するものではありません。

## 書き込み

対象機種のラベルが **M5StickC Plus SE / K016-P-SE** であることを確認し、USBデータケーブルで接続します。

```sh
pio device list
pio run -e m5stick-c-se -t upload --upload-port /dev/cu.YOUR_DEVICE
pio device monitor --port /dev/cu.YOUR_DEVICE --baud 115200
```

Windowsではポートを `COM番号` に置き換えます。書き込み速度はSE公式資料にある115200bpsです。必要な場合は公式FTDIドライバを導入してください。2026-10-03に `/dev/cu.usbserial-854ED96FEE` へ通常版を書き込み、4領域のハッシュ照合に成功しました。

ビルド出力は `.pio/build/m5stick-c-se/firmware.bin`。配布用は `artifacts/m5stick-c-se/` にまとめています。`firmware.bin` はアプリ部分であり、アドレス0に単独で書かないでください。通常は上記のPlatformIO uploadを使用します。配布したバイナリをesptool 4.9.0で直接書く場合は以下です。

```sh
python -m esptool --chip esp32 --port YOUR_PORT --baud 115200 write_flash \
  --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x1000 artifacts/m5stick-c-se/bootloader.bin \
  0x8000 artifacts/m5stick-c-se/partitions.bin \
  0xe000 artifacts/m5stick-c-se/boot_app0.bin \
  0x10000 artifacts/m5stick-c-se/firmware.bin
```

## 操作

画面を横向きにします。初期値rotation=3はFactoryと同じです。正面のAと側面のBを操作し、電源ボタンはゲームに使いません。画面が読める向きで持ってください。左右どちらの持ち方が操作しやすいかは実機未検証です。

| 画面 | A | B |
| --- | --- | --- |
| 選択（5ゲーム＋設定） | 次の項目 | 決定 |
| 説明 | 開始 | 選択へ |
| 結果 | 再挑戦 | 選択へ |
| 設定 | 次の項目 | 変更・実行 |
| 記録リセット確認 | 取消 | 2秒保持で全記録を消す |

プレイ中はA+Bを800ms保持すると中断します。中断した記録は保存しません。画面遷移後は両ボタンを一度離してください。通常の短押しは解放時に確定し、800ms以上の長押しは短押しになりません。説明・結果・設定などで30秒無操作なら選択に戻ります。

| ゲーム | 遊び方・得点 |
| --- | --- |
| ホームラン競争 | 球がバットの基準線に来る瞬間、Aを押す。1球1スイング、10球の合計。誤差50/100/150ms以内で100/50/20点。 |
| チキン風船 | A短押しで10点ずつ膨らませ、B短押しで確定。12〜24段階の隠れた破裂位置に達すると0点。15秒で現在点を確定。 |
| 記憶スイッチ | 提示されるA/B列を覚え、同じ順で短く押す。各入力3秒以内。長さ2から12まで増え、最後に完全正解した長さが得点。 |
| 声で浮く気球 | 校正後、声で上昇・静かにすると下降。障害物を20秒避ける。ボタン版はA保持で上昇。記録はモード別。 |
| ぴったり10秒 | READYでA押下から計測。離してから次のA押下で停止。2秒後に時計が隠れる。誤差が小さいほどよく、20秒のTIME OUTは記録対象外。 |

自己ベスト更新・設定変更・明示的な記録リセット時だけNVSに保存します。未記録と0点/誤差0msは別管理です。全記録リセットは設定を保持します。NVS読込不正/旧schemaでは初期値、保存失敗ではRAM上でゲームを続けます。右下の赤い小丸とSerialの `NVS:` ログが保存エラーを示します。

## 展示とマイク

USB給電で使用し、明るさを会場に合わせて3段階から選びます。バッテリー持続時間は未測定です。

音声モードでは毎プレイ、周囲の音2秒→「あー」の発声2秒を測ります。Bで最初から測り直せます。普段の声で測ってください。環境音との差が小さい・録音失敗・500ms取得が進まない場合は、Aで再測定、Bでボタンモードを最初から開始できます。設定内の再校正だけを試している場合、Bは設定へ戻ります。校正値は保存せず、次の声プレイでも必ず再校正します。

校正・音声ゲーム・そのカウントダウンでは効果音を抑止します。音声取得前にブザーのI2Sを停止し、マイク終了後の結果画面では効果音を鳴らせます。会場の雑音で反応が不安定な場合は、設定の「気球モード」をボタンにしてください。声とボタンの自己ベストは混ざりません。

## 調整値

主な値は `include/config.hpp` に集約しています。仕様のゲーム採用・テーマ・追加機材なしは変更していません。

| 項目 | 値 | 仕様初期値との差・理由 |
| --- | --- | --- |
| 画面 | 240×135、rotation=3 | Factoryの向き。実機での持ちやすさは要確認 |
| 描画/入力 | 約30fps / 約1msごと＋描画処理時間 | 入力と描画の時計を分離 |
| デバウンス/中断 | 20ms / 800ms | デバウンスは追加の初期値。raw GPIOで二重デバウンスを避ける |
| カウントダウン | 500ms×3 | 仕様どおり |
| 打撃の待機/飛行/表示 | 500〜900ms / 700〜1100ms / 600ms | 仕様どおり |
| 風船破裂/制限 | 12〜24段階 / 15秒 | 仕様どおり |
| 記憶列 | 450ms表示＋150ms空白、入力3秒、最大12 | 仕様どおり |
| 時間判定 | 打撃・風船・記憶入力・10秒停止に20msのイベント確定猶予 | 判定基準は元の押下/解放時刻。期限直前の入力がデバウンスで届く前に失格になることを防ぐ |
| マイク | 16kHz / 256サンプル / DC除去RMS / alpha=0.2 | 仕様どおり。ライブラリのover_sampling=1 |
| 校正成立 | 両フェーズ20フレーム以上、声−周囲RMS≥30 | 誤差の小さい校正を除外する初期値。実機の感度は未調整 |
| 取得失敗 | 500msでエラー選択へ | 永久待機防止の初期値 |
| 気球 | 下向き速度45−100×level px/s、70px開口、60px/s、2秒間隔 | 仕様どおり。ゲーム領域y=26〜111内へ開口中心を制限するため、移動幅は最大15px（指定の最大25px以内） |
| 当たり判定 | 気球半径7px、障害物幅18px、10ms以下の物理刻み | 表示より小さい判定。低fpsでのすり抜けを防止 |
| 明るさ | 64 / 128 / 220 | 3段階の具体的な初期値 |
| NVS | schemaVersion=1、44バイトの固定形式＋チェックサム | 不正値・旧形式を安全に除外 |

開発モード：`pio run -e development`。乱数seed=12345、風船破裂=16に固定します。展示には通常の `m5stick-c-se` を使ってください。

## 検証と構成

ロジックの実行結果と未検証事項は `docs/VALIDATION.md` に記載しています。実機チェックリストは `docs/HARDWARE_CHECKLIST.md` です。

[画面プレビュー](docs/UI_PREVIEW.png)は実際の描画コード・フォントから生成したPC上の画像です。

```text
include/         調整値、入力、ゲーム/アプリのデータモデル
src/app/         共通画面遷移、記録更新、設定、校正
src/games/       5ゲームとRMS・保存形式のハードウェア非依存ロジック
src/platform/    SE初期化、Canvas描画、非同期録音、ブザー、Preferences
test/            ロジックテストと描画プレビュー
lib/             固定したM5Unified/M5GFXのソース・ライセンス
docs/reference/  確認した公式Factoryの設定と初期化処理
artifacts/       書き込み用バイナリ
```

録音バッファ256サンプルは起動時の固定配列です。1要求だけをM5Unifiedの録音タスクに渡し、`isRecording()==0` を確認してからRMSを読みます。終了時の `Mic.end()` 完了までバッファを再利用しません。ゲーム配列・記憶列・障害物も固定サイズ、Canvasは起動時に1回確保します。

SDL2開発環境が既にあるPCでは `python3 scripts/preview.py` で実際のM5GFX描画と同梱フォントによる画面を `build/previews/` に生成できます。これは実機の見え方や入力遅延の検証には代わりません。追加のSDL2導入はESP32向けビルドに不要です。

出典・ライセンスは `THIRD_PARTY_NOTICES.md`、同梱ライブラリの固定ソースのハッシュは `docs/DEPENDENCIES.sha256` を参照してください。
